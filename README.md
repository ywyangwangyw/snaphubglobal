# SnapHub Global

SnapHub Global is an electronic components and devices reseller.

## Overview

This repository is the home for SnapHub's business operations, documentation, and tooling.

## Structure

```
docs/         Company and process documentation
operations/   Day-to-day operational workflows and scripts
inventory/    Inventory tracking and catalog management
```

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

Keep sensitive credentials out of version control — use environment variables or a secrets manager.
